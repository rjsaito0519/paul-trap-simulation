# 開発ロードマップ

## Phase 0: 設計確定

- 符号、単位、座標、状態ベクトルを確定する。
- Floquet安定、有限時間捕獲、捕獲確率の用語を確定する。
- 最小対応環境と必須依存関係を決める。
- ROOTは使用せず、C++とPythonのみで構成する（2026-10-06決定）。
- 結果形式と設定形式を代表データで比較する。

完了条件: model、stability、architecture、validationの未決事項が、実装者が推測しなくてよい程度に決まっている。

## Phase 1: Python参照計算

- 1方向のモノドロミー行列を計算する。
- 小さい`(a, q)`格子を描画する。
- `b = 0`の既知境界と比較する。
- 軸方向と半径方向の共通安定領域を作る。

完了条件: 既知境界、行列式、step幅収束が検証されている。

## Phase 2: C++ Floquetエンジン

- Python参照実装と同じ入出力を定義する。
- 固定刻み積分、2×2固有値、境界分類を実装する。
- OpenMPでパラメータ点を並列化する。
- Pythonとの回帰テストと性能測定を行う。

完了条件: 指定精度でPythonと一致し、再現可能な性能測定がある。

## Phase 3: 境界追跡と3次元パラメータ

- 粗格子から境界を抽出する。
- 二分法またはcontinuationで境界を高精度化する。
- 複数の`b`で境界面を構成する。
- 必要な解像度と保存形式を決める。

完了条件: 全面密格子より少ない計算量で、同等以上の境界精度を得る。

## Phase 4: 軌道と有限電極

- 2Dと3Dの粒子軌道を実装する。
- 重力、Stokes抵抗、脱出イベントを含める。
- 初期条件と観測時間を明示する。
- Floquet安定と幾何学的捕獲の差を比較する。

完了条件: 単位変換、極限、イベント、step幅のテストがある。

## Phase 5: 捕獲確率

- 初期条件と物理量の分布を設定化する。
- 決定論的な並列乱数系列を使用する。
- 確率と統計誤差を出力する。
- 実験パラメータ`(V_DC, V_AC)`へ換算した図を作る。

完了条件: seed、サンプル数、信頼区間、観測時間から結果を再現できる。

## Phase 6: 可視化

- 安定領域、境界面、捕獲確率の静止画を作る。
- 粒子と電極を表示する2D・3D GIFとMP4を作る。
- 回転、ズーム、再生、一時停止、時間スライダーを持つ3D HTMLを作る。
- 軌道データと描画処理を分離する。

完了条件: 同一結果から静止画、動画、インタラクティブ表示を再生成できる。

## 未決事項

- Cunningham補正や非線形抗力を追加する条件
- 理想四重極から実電極電場へ移行する条件
- HDF5、Zarr、NumPy形式などの結果形式の選択
- CLI実行ファイルとpybind11の境界
- 公開リポジトリに適用するライセンス
