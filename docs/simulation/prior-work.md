# 既存ノートの確認結果

既存の非公開作業ノート2件を2026-10-06に確認した。この文書では、再利用する考え方と解消すべき問題だけを記録し、ノートやクラウドストレージへのリンクは公開しない。

## paultrap_analysis

実験データ解析と、過去に計算したシミュレーション結果の後処理が中心である。

- 無抵抗Mathieu方程式の特性曲線を級数近似し、軸方向と半径方向を同時に満たす安定領域を描画している。
- `a_z = -2 a_r`、`q_z = -2 q_r`の関係を使用している。
- Stokes抵抗から`b = 9 eta / (R^2 rho Omega)`を使用している。
- 事前計算済みデータから`b`と`q_max`をフィットし、`q_max = alpha b`として扱っている。表示結果は`alpha = 2.854288`。
- 掲載パラメータでは`b = 6.04667`であり、フィットから`q_max = 17.2589`となってノートの表示と一致する。
- 主な計算結果はノート外の事前計算データに依存し、ノート単独では再計算できない。

このプロジェクトでは、事前計算CSVに依存せず、安定判定をリポジトリ内の数値計算で再生成できるようにする。

## PaulTrapのシミュレーション

単一粒子の軌道を固定刻み4次Runge–Kutta法で計算する、比較的自己完結したノートである。

- 空気抵抗、重力、理想四重極電場を含む。
- 無次元時間`tau = Omega t / 2`を使用する。
- 状態は`[z, dz/dtau, r, dr/dtau]`。
- 電極寸法`z0`または`r0`を越えた履歴があれば脱出と判定する。
- 軌道と時間変化は静止画であり、GIFや操作可能な3D表示はない。

実装前に解消すべき点:

- `V_ac = 4000 V`を定義する一方、実際の計算では独立な`q_z = 0.79`を使用している。掲載物理量では`q_z = 0.79`は約545 Vに相当し、4000 Vは`q_z`約5.80に相当する。
- 初速度のUI値が物理速度`dz/dt`か無次元速度`dz/dtau`か明確でない。物理速度を受け取る場合は`dz/dtau = 2(dz/dt)/Omega`へ変換する。
- `numpy.float`は現在のNumPyでは使用できないため、将来の実装では`float`または明示的な浮動小数点型を使用する。
- 標準設定は無次元時間50、RF約15.9周期に相当し、長時間安定性の判定には短い。
- 符号付き`r`は円筒半径ではなく、半径方向の1直交座標として解釈する必要がある。

## 引き継ぐもの

- 無次元化と符号規約の基本形
- Stokes抵抗の定義
- 軌道、時系列、電極形状を同時に示す可視化の考え方
- 実験パラメータと無次元パラメータの往復変換

## 引き継がないもの

- 共有ドライブ上の暗黙なファイル構成
- 有限時間の脱出判定をFloquet安定性と同一視すること
- 単位が不明確な初期速度
- 依存関係の実行時インストールと、セル実行順に依存する状態
