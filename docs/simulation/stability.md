# 安定領域の数値計算法

## Floquet判定

各方向の同次方程式

```text
x'' + b x' + (a - 2 q cos(2 tau)) x = 0
```

を1階化し、係数の1周期`pi`にわたって2本の独立な初期条件を積分する。周期末の基本解行列をモノドロミー行列`M`とする。

Floquet乗数を`lambda_i`とすると、減衰系では原則として

```text
max(abs(lambda_i)) < 1
```

を漸近安定と判定する。境界の丸め誤差を避けるため、実装では許容値と「境界」分類を別に持つ。

Phase 1の暫定値として、`rho = max(abs(lambda_i))`に対し

```text
rho < 1 - eps  : stable
rho > 1 + eps  : unstable
otherwise      : boundary
eps = 1e-8
```

を用いる（2026-10-06時点の暫定値）。収束試験の結果を見て確定値をこの文書に記録する。

`b = 0`では`det(M) = 1`であり、安定領域全体で`rho = 1`となるため上記の判定は使えない。この場合は有界性（Lyapunov安定）を

```text
abs(tr M) < 2 - eps : stable
abs(tr M) > 2 + eps : unstable
otherwise           : boundary
```

で判定する（2026-10-06決定）。これは`b > 0`の判定の`b -> 0+`極限と一致する。

2×2行列なので一般固有値ソルバーは必須ではない。トレースと行列式から固有値を求められる。またLiouvilleの公式により

```text
det(M) = exp(-b pi)
```

であるため、積分精度の診断に使用する。

## ポールトラップとしての判定

1つの`(a_z, q_z, b)`に対して、次の両方を計算する。

```text
axial: (a_z, q_z, b)
radial: (-a_z/2, -q_z/2, b)
```

両方向が安定な点だけをポールトラップのFloquet安定領域とする。`x`と`y`は理想軸対称モデルでは同じ半径方向判定を共有する。

## 探索戦略

高密度3次元格子を全面走査する前に、次の段階を採用する。

1. 粗い`(a_z, q_z)`格子で領域を把握する。
2. 安定・不安定が隣接するセルだけを細分化する。
3. 固定`b`で境界曲線を追跡する。
4. 隣接する`b`の境界を次の探索初期値にする。
5. 必要な場合だけ内部領域を高密度に塗る。

境界だけが目的なら、3次元ボリューム全体を保存せず、continuationまたは二分法で曲面を追う。捕獲確率マップでは内部値が必要なため、別の走査ジョブとする。

## 境界追跡の実装（2026-10-06、Phase 3）

`floquet_boundary`は固定`b`の断面ごとに独立に境界を求める。隣接`b`からのcontinuationは、断面あたり1〜2秒で済むため現時点では使わない。

- 判定量: 安定余裕`g = max(g_axial, g_radial)`。`b > 0`では`g = log(max|lambda|)`、`b = 0`では`g = |tr M| - 2`。`g < 0`を安定、`g >= 0`を非安定とし、`eps -> 0`で上記分類と一致する。
- 手順: 粗格子で`g`を計算し、符号が変わる格子辺だけを二分法で許容幅`1e-9`まで細分化する。marching squaresで境界点を折れ線につなぎ、4辺すべてが交差するsaddleセルはセル中心の`g`で解決する。
- 範囲: 指定窓内のすべての安定領域を対象とし、格子上で連結な安定領域に番号を付ける（第一安定領域に限定しない）。既定の窓は`a_z in [-3, 3]`、`q_z in [0, 30]`、`b in [0, 10]`。
- 目標精度: 境界位置の絶対誤差`1e-6`（`(a_z, q_z)`単位）。
- 既知の制約: 粗格子の間隔より細い安定領域（島）や、1つのセル内で2回交差する境界は検出されない。領域数は粗格子に依存するため、領域の数や島の有無を結論にする場合は格子を細かくして変化しないことを確認する。
- 原点`(a_z, q_z) = (0, 0)`ではすべての境界が接し`g`がほぼ0になるため、境界位置の数値精度が落ちる（`1e-7`〜`1e-6`程度）。

## 計算エンジン

- 参照実装: Pythonで少数点を高精度に計算する。
- 本番実装: C++の固定刻み高次積分とOpenMP並列化を第一候補とする。
- 各パラメータ点は独立なので、並列化の単位を明確にする。
- GPUは、大規模な固定刻み走査の必要性が測定で確認されてから検討する。

## 有限時間捕獲

Floquet判定とは別に、重力と有限電極を含む軌道を積分する。脱出面へのイベントを検出し、脱出時刻、最大半径、最大軸変位を保存する。

脱出判定（2026-10-06決定）: 理想四重極電位の等電位面である双曲面電極への到達を脱出とする。

```text
ring:    x^2 + y^2 - 2 z^2 = r0^2
endcaps: 2 z^2 - (x^2 + y^2) = 2 z0^2 = r0^2
```

既存ノートの箱型判定（`abs(z) > z0`または`sqrt(x^2 + y^2) > r0`）は採用しない。実電極は有限の大きさで切られており、電極端付近の電場は理想四重極と異なるため、電極端近くを通る軌道の結果は理想モデルの範囲でのみ有効である。

Phase 4の参照実装は`scripts/trajectory.py`（scipy `solve_ivp` DOP853、`rtol = 1e-10`、`atol = 1e-13`、最大step `pi/20`、電極面をterminal eventで検出し、衝突点を最終サンプルとして保存）。

捕獲確率を求める場合は、初期位置、初速度、粒径、電荷などの分布とrandom seedを必ず保存する。観測時間を変えた収束も確認する。
